# ToolboxPanel 2.0.6 —— 主题引擎做全 + 两处显示 bug 修复 + 代码体检（第二轮）

> 本版三块内容：**主题引擎补齐**（5 预置 + 外观微调）、**两个你实测报上来的显示问题**（图标黑方块 / 设置面板发黑），
> 外加一轮**系统性代码体检**（12 处真 bug/漏洞 + 删约 500 行冗余）。
> **没有破坏性变更**：`data/tabs.json` 与 `data/config.json` 格式不变，旧版数据与备份包照旧可用。

## 新增

### 🆕 主题引擎做全（5 预置 + 外观微调）
设置面板 →「主题」一节：**跟随系统 / 深色 / 浅色 / 午夜蓝 / 葡萄紫 / 抹茶绿**，点一下即时生效。

- **午夜蓝 / 葡萄紫 / 抹茶绿** 是本版新加的彩色预置：窗口色相、强调色（选中条、落点指示线）、
  面板底色会一起变；颜色与参数**逐字照抄**原版实现，并有"与原版逐字段比对"的保真测试守着。
- 新增「**外观微调**」一节，**6 个滑杆**即时生效并自动保存：
  窗口不透明度 · 卡片不透明度 · 卡片悬停 · 圆角 · 悬停时长 · 抽屉不透明度
  （「模糊强度」在系统材质下不可调，故不提供；「动效时长」与「动效」节里的时长是同一个值，只保留一个入口）
- 底部「**恢复默认外观**」一键回到当前预置的原样；配置文件里手写的逐令牌颜色覆盖也照旧生效。

## 修复（都是你实测发现并反馈的）

### 🐞 图标背后有黑方块（浅色主题下最明显）
有的图标背景是半透明的、有的却是一块黑。根因：图标提取时把**用掩码表示透明**的那些图标
（资源管理器里的文件 / 快捷方式图标）的透明区误当成了不透明黑。
现已修好，并且**已有的图标缓存会在下次启动时自动重新提取一次**（沿用原文件名，数据文件不受影响）。

### 🐞 设置面板整块发黑（鼠标移上去就变黑）
根因：面板的玻璃效果缺少色调层，颜色会跟着"窗口背后是什么"变——背后是深色就整块发黑；
而且在部分显卡/驱动组合下，即使补上色调层也仍会被系统合成成黑色。
现在面板改用**实心表面**（不再依赖系统合成层）：**浅色主题就是浅面板、深色主题就是深面板**；
想要玻璃观可以用「外观微调 → 抽屉不透明度」把它调透。

### 🐞 设置里的按钮/滑杆不好点中
- **滑杆现在整条轨道都能点、能拖**（原先只有那个小圆点能拖，得对准才行）；
- 面板右上角的关闭按钮、以及标题栏的 **设置 / 关于 / 搜索** 三个按钮命中区都放大了；
- 拖动滑杆时不再每一下都做整套重绘，手感更跟手。

### 🐞 其它
- **搜索框**：干掉内层文本框自带的聚焦下划线（它只覆盖文字区，看着左右不对称），聚焦提示改由外层圆角容器承担；
  搜索栏弹出/收起改成平滑动画（原来是把内容区"蹦"一下挤下去）。
- **标题栏文字重新对齐**（放大按钮时被顶高了几个像素）；关掉"鼠标停在窗口里就飘出一个快捷键小方框"的系统行为。
- **快捷键设置**从只读的「快捷键参考」升级为**可改键**：录制新组合、单条/全部恢复默认，
  并做冲突检测（应用内四类判据 + 实测"是否已被其它程序占用"）；入口在**设置面板**里。

## 质量（代码体检第二轮）

- 三份只读审计（Core / 界面 / 测试与数据安全）+ 逐条复核，落地 **12 处真 bug/漏洞**，其中较重的三条：
  - 拖动排序在"数据里出现重复 id"时会**直接崩**（并会静默丢项）；
  - `config.json` 里某个字段类型写错会让**整份设置静默变默认值**；
  - 按"重置数据"会把图标缓存的格式标记一起删掉（导致下次启动白重提一遍全部图标）。
- 删掉约 **500 行**冗余：两个页面逐字重复的拖放落点/指示线代码收口成 `DragDropShared`（改一次只改一处），
  以及 15 个已无人引用的死成员。
- **测试不再假绿**：需要真实 Python 对照的 9 条测试，以前"找不到 python 就静默算通过"，
  现在报告里显示**已跳过**；而在开发副本里"明明有原版源码却探测不到 python"会**显式失败**。
- 单测 **472 → 571 项全绿**；编译 **0 警告 0 错误**。
- ⚠️ **拖拽（同页重排 / 跨页移动 / 从资源管理器拖入）**本轮动了内部结构，代码逐字未改行为，但仍建议你实机试一下。

## 运行要求
- **仅支持 Windows 11**（窗口材质用 Mica；Win10 由系统自动回退纯色）
- **免安装**：解压即用（Windows App SDK 自包含），无需 MSIX 与证书

## 数据兼容（与旧版互通）
- `data/tabs.json` 格式**不变**（`version: 1`）：v1.11.6 / 2.0.1 ~ 2.0.6 互相可读可写

  旧版读到会原样保留；没被改过的配置写回**逐字节不变**
- **备份包（导出 / 导入 ZIP）与旧版双向兼容**（均有测试）

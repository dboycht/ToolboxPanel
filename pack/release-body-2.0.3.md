# ToolboxPanel 2.0.3 —— 中英双语（i18n）

> 本版是**功能补齐版**：把整个界面做成**中英双语**，并可在设置里**即时切换（无需重启）**。
> **没有破坏性变更**：`data/tabs.json` 格式不变，配置项只增不改，旧版数据与备份包照旧可用。

## 本版内容

### 🆕 语言切换（设置面板 → 「语言」一节）
- 可选 **中文 / English**，**切换后界面立即整体换成所选语言**，偏好写入 `config.json`（下次启动记住）
- 覆盖范围：标题栏提示、状态栏、搜索栏（占位与关闭提示）、批量管理条、空页 / 无匹配提示、
  标签栏数量（"20 个图标" / "20 icon(s)"）、以及**所有对话框**——
  关于、新建 / 编辑图标、重命名图标、列表项新建 / 编辑 / 重命名、备份导入导出进度与确认框

### 文案与原版对齐
- 中英文案表 **374 条**，key 命名与原版 v1.11.6 的 `i18n.py` **完全一致**（原有 key 一个未改名）
- 有一条**保真测试**：用**真实原版 Python** 解析 `i18n.py`，与 C# 侧的表**逐 key、逐语言逐字**比对
  （含多行文案与 `{name}` 这类占位符）—— 单边改动会被测试挡住
- 占位符沿用原版语义：缺参数时**原样保留** `{name}` 而不报错；未知 key 显示 `??key??`（便于发现漏配）

### 有意保留原样的地方
- **开发者诊断日志**（`%TEMP%` 下的自检 / 拖动链路 / 崩溃日志）与 `--demo` 演示数据：只给开发用，不随语言变
- **用户数据里的名字**（图标名 / 列表项说明 / 标签页名 / 路径）：属于**你的数据**，切语言**不会改写**；
  示例图标的名字跟随"首次创建那一刻"的语言

## 运行要求
- **仅支持 Windows 11**（窗口材质用 Mica；Win10 由系统自动回退纯色）
- **免安装**：解压即用（Windows App SDK 自包含），无需 MSIX 与证书

## 数据兼容（与旧版互通）
- `data/tabs.json` 格式**不变**（`version: 1`）：v1.11.6 / 2.0.1 / 2.0.2 / 2.0.3 互相可读可写
- **备份包（导出 / 导入 ZIP）与旧版双向兼容**（均有测试）：
  - 旧版导出的包 → 本版可正确导入（含旧版在 Windows 下写出的 `data\tabs.json` **反斜杠**包）
  - 本版导出的包 → **旧版可正确导入**（本版统一写正斜杠 `data/`，而旧版导入只认这个前缀）
- `config.json` 新增键（`language` / `icon_size` / `ui_theme` / `backdrop` / `tab_icon_mode` /
  `show_tab_counts` / `animations` / `animation_duration_ms` / `animation_easing` / …）
  **旧版读到会原样保留**，不影响使用

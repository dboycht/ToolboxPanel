# ToolboxPanel 2.0.5 —— 标签页管理 + 快捷键体系

> 本版把**老版本有、而这一线一直缺**的两块补齐：**标签页管理**与**快捷键**。
> **没有破坏性变更**：`data/tabs.json` 格式不变、配置项不变，旧版数据与备份包照旧可用。

## 新增

### 🆕 标签页管理（此前**根本无法新建标签页**）
这是一个长期被忽略的缺口：数据层早就写好了新建 / 重命名 / 删除，但界面上**一个入口都没有** ——
你只能用首启自动建的那一页，或者手工改 `tabs.json`。现在：

- **标签上右键** → 新建标签页 / 新建列表标签页 / 重命名 / ─── / 删除
- **标签栏空白处右键** → 只出两个「新建」
- **新建**：名字框预填默认名；确定后新页**立刻被选中**且是空的
- **新建列表标签页**：出来的是两列列表页（说明 / 路径），和已有的列表页一样
- **重命名**：预填当前名；确定后**标签栏上的名字立即变**（不用重启）
- **删除**：先二次确认，然后切到旁边的页 —— 且**至少保留一个标签页**（删到只剩一个会被拒绝）
  - 删除一个**非当前**标签页时，**你正在看的那一页不会被切走**

### 🆕 重置数据（此前**完全没有**）
设置面板 →「数据」一节 →「重置数据」：二次确认后清空所有标签页与图标缓存、重建一个默认页。
（注意与面板底部的「恢复默认设置」区分：那个只把 `config.json` 恢复默认值，不动你的内容。）

### 🆕 快捷键体系（此前只有 4 条）
现在有 **17 条**，并在标题栏新增 **❓ 按钮**打开「快捷键参考」窗口（一张"功能 × 快捷键"表）：

| 功能 | 快捷键 |
| --- | --- |
| 新建标签页 | `Ctrl+T` |
| 新建列表标签页 | `Ctrl+Shift+T` |
| 重命名标签页 | `Ctrl+R` |
| 关闭当前标签页 | `Ctrl+W` |
| 上一个 / 下一个标签页 | `Ctrl+Shift+Tab` / `Ctrl+Tab` |
| 查找图标 | `Ctrl+F` |
| 批量管理模式 | `Ctrl+B` |
| 批量删除图标 | `Shift+Delete` |
| 新建 文件 / 文件夹 / 快捷方式 / 网址 / 命令 图标 | `Ctrl+Shift+F` / `O` / `L` / `U` / `P` |
| 重置数据 | `Ctrl+Shift+R` |
| 导出 / 导入备份 | `Ctrl+Shift+E` / `Ctrl+Shift+I` |
| 退出程序 | `Alt+F4`（系统级） |

**快捷键不会抢你正在打的字**：焦点在搜索框/输入框里时，除 `Ctrl+F`（它本身就是搜索栏的开关，
再按一次关掉）以外的快捷键一律不生效 —— 例如在搜索框里按 `Shift+Delete` 是**剪切文字**，
不会去删图标；对话框开着时也不会误触发（不会再弹出第二个对话框）。

## 说明
- **标签页拖动重排不在这一版**（留到以后单独做）：标签顺序暂时按创建顺序，
  要调整顺序可以后续版本再看。
- 图标本身的 F2 改名 / Delete 删除**没有做快捷键**：本实现的页面里没有"选中项"这个概念
  （单击/双击即打开，选择只有批量模式的勾选框），硬加会做成"按了没反应"的哑快捷键。
  "删除勾选项"这条路已由 `Shift+Delete` 覆盖。

## 运行要求
- **仅支持 Windows 11**（窗口材质用 Mica；Win10 由系统自动回退纯色）
- **免安装**：解压即用（Windows App SDK 自包含），无需 MSIX 与证书

## 数据兼容（与旧版互通）
- `data/tabs.json` 格式**不变**（`version: 1`）：v1.11.6 / 2.0.1 ~ 2.0.5 互相可读可写
- **备份包（导出 / 导入 ZIP）与旧版双向兼容**（均有测试）：
  - 旧版导出的包 → 本版可正确导入（含旧版在 Windows 下写出的 `data\tabs.json` **反斜杠**包）
  - 本版导出的包 → **旧版可正确导入**（本版统一写正斜杠 `data/`，而旧版导入只认这个前缀）

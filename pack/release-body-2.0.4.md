# ToolboxPanel 2.0.4 —— 稳定性修复：代码体检 + 单实例

> 本版是**修复 / 加固版**：做了一轮系统性的代码体检（修 bug、删冗余、增强壮性），
> 并修好你反馈的「重复启动会开多个实例」。
> **没有破坏性变更**：`data/tabs.json` 格式不变、配置项不变，旧版数据与备份包照旧可用。

## 修复（都是你可能真的会遇到的）

### 🐛 导入备份失败不再清空你的数据（最重要的一条）
原来的顺序是**先清空再解压**：只要压缩包有一点问题（截断、某个文件被占用、磁盘满、路径过长），
程序已经把 `icons/` 与 `tabs.json` 删干净了，然后才失败 —— 你看到的是"导入失败"外加"图标全没了"。
现在改为**先把包内容解到暂存区、确认可用之后才动你的数据**：
任何环节失败都保证**一个字节都不改**。

顺带把导出也改成"先写临时文件、全部成功才落成正式 zip"——
中途失败不会再留下一个半截包（而半截包正是导入时最危险的输入）。

### 🐛 重复启动：已有窗口会被拉到前台 ⭐
以前"双击第二次"确实不会开新窗口，但**已有窗口不会升起来** ——
因为让"即将退出的第二个进程"去操作"别人的窗口"会被 Windows 前台锁拒绝，
于是第二个进程悄悄退出、看起来像"没反应"。
现在改为**第二个实例通知已有实例，由窗口自己恢复并前置**（最小化时也会被恢复），
并连按多次也只保持一个窗口。用的是各家单实例应用的标准做法。

### 🐛 拖动：取消的拖动不再被误当成"落下"
快速连续拖动时，上一轮残留的标记可能被当成本轮的"松手落点"，
导致一次本该被取消的拖动把顺序改掉。现在只认"收口那一刻"的快照。

### 🐛 编辑图标时点「浏览…」选文件失败不再闪退
选择器抛错时，异常会直接穿到事件处理器导致进程直接退出。现在在底层收口，失败按"取消"处理。

### 🔒 安全 / 健壮性加固
- **图标缓存文件名不再能越出数据目录**：`icon_cache_file` 是磁盘上的字符串，
  以前一个形如 `..\config.json` 的值会让"清理图标缓存"删到你的**设置文件**（导入别人给的备份包也会中招）。
  现在只接受"裸文件名"，拼好后再复核一次路径。
- **不再漏 GDI 句柄**：图标提取失败路径会漏一个系统图标句柄，长期使用会缓慢耗尽 GDI 对象。
- **写盘更稳**：保存 `tabs.json` / `config.json` 现在是"同一目标排队 + 失败不留临时文件"。

### 🐛 其它小修
- **图标缓存目录会回收没人引用的旧图**（此前只增不减）
- 拖动链路诊断日志（`%TEMP%\toolboxpanel-probe.log`）从**第二次拖动**起不再失效
- 自检文件（`%TEMP%\toolboxpanel-verify.txt`）不再显示"窗口材质：未初始化"
- 示例图标的路径字段口径与「新建图标」对齐；批量补示例图标由 20 次全量写盘降为 1 次
- 从过滤（搜索）结果里重命名后，勾选状态与"已选 N 个"计数不再对不上

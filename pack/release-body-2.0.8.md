# ToolboxPanel 2.0.8 —— 标签页拖动重排 + 图标跨页面拖动（含 4 处实测修复）

> 本版两件事：① 新增**标签页拖动重排**（把标签拖到新位置）；
> ② 把**图标跨页面拖动**从"代码里有、实际用不了"修到真能用（三处根因 + 两处体验问题）。
> **没有破坏性变更**：`data/tabs.json` 与 `data/config.json` 格式一字未改，旧数据与旧备份包照旧可用。

## 新增

### 🔀 标签页拖动重排
- **按住标签横向拖** ⇒ 标签之间出现**插入竖条**，松手即换位置；拖到标签栏右侧空白处 = 放到最后；
- **拖回原位**（小幅拖动后松手）与**拖动中按 `Esc`** 都不改顺序；
- 拖动期间**内容区不跟着翻页**；松手后**被拖的那个标签仍是当前页**；
- 与"把图标拖到标签上做跨页移动"互不干扰 —— 一次拖动只会是其中一种。

## 改进

### 📦 图标跨页面拖动（把图标从一个标签页搬到另一个）
- **把图标拖到另一个标签上松手** ⇒ 追加到那一页**末尾**；**源页那一个会消失**（不会两边都有）；
- **鼠标移到哪个标签，就立刻切到哪一页**（本版由"停半秒才切"改成**立刻**），
  切过去后可以在该页里**选位置放下**（精确落位那条路）；
- 拖动经过标签时，那个标签会有一圈**强调色描边**（提示"松手就落进这一页"）；
- 搬过去的图标**当场就显示图案**（不必再右键「刷新图标」）；
- 不同类的内容仍然互斥：图标丢到列表页 / 文本页的标签上会被明确拒收（状态栏给一句提示）。

## 修复（都是你实测发现并反馈的）

### 🐞 跨页搬过去的图标，源页还留着一个
同一图标出现在两个页面上（重启后才正常）—— 界面集合的同步代码**只重排、不删除**
已经不在数据里的项。现在判断收进 Core 的 `CollectionSync`：
**该删的删 / 该挪的挪 / 该插的插**（`ObservableCollection` 走 `Move`，保住容器与滚动位置）。

### 🐞 拖到标签名字上完全没反应
拖放的**命中判定**在真实拖动时拿不到标签栏（而"拖标签"却一切正常 —— 日志里两条事实对照极清楚）。
现在改成**按指针坐标**判定（不再依赖"框架把事件交给哪个元素"），并把拖放处理器挂到标签栏
**外层容器**、以"即使被子元素标记已处理也照样收到"的方式再挂一遍。

### 🐞 搬过去的图块是空白
它"已经加载好位图的实例"留在了源页，目标页补建的新实例没有图源 ⇒ 图块空白（要右键「刷新图标」才显示）。
现在**把实例直接搬过去**（连已解码的位图一起），并保留一条"从已有缓存读图"的兜底。

### 🐞 跨区域松手时偶尔被当成"取消"
落库判定原先只剩一个信号（`DropResult`），而跨区域拖动时 `Drop` 落在**目标**那一侧、
源侧自己的"落下过"标记永远是假。现在补了一条**会话级**"确实落下过"的证据（三个信号取或）。

- 新增 Core `CollectionSync`（"界面集合跟随数据源"的判据，9 条单测）

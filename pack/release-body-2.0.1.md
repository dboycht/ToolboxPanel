# ToolboxPanel 2.0.1 —— 大版本重构：UI 前端推倒重来（WinUI 3）

> 从本版起，界面由 **WinUI 3 / Windows App SDK（C#，单进程）** 实现；
> 视觉层与数据层全部为 C#，Python/Qt 实现保留为备选（不再加载）。

## 本版内容

### 窗口与观感
- 无边框自绘标题栏 + 系统窗口按钮（保留缩放 / 贴边分屏 / 圆角阴影）
- 窗口材质：Mica / MicaAlt / 桌面 Acrylic / 纯色，可切换（系统不支持时自动回退）
- **主题**：跟随系统 / 浅色 / 深色，**全局生效**（主窗口、标签栏、状态栏、设置面板同一套令牌）
- 设置面板为半透明玻璃表面（元素级 Acrylic），随主题变化

### 标签页与图标
- 横向标签栏：网格页 / 列表页两种类型；标签图标三态（只文字 / 常驻 / 悬停浮现）
- 图标覆盖 5 类：文件 / 文件夹 / 快捷方式 / 网址 / 命令；自动提取系统图标并缓存，点击即打开
- **拖拽排序**：同页重排 + **跨页移动**（拖到标签上停一下自动切页；直接松手在标签上则追加到该页末尾）

### 动效
- 切页整片淡入（时长 / 曲线可调）；设置面板滑入 / 滑出；标签悬停平滑展开收起

### 数据兼容
- `data/tabs.json` 格式**不变**（`version: 1`），v1.11.6 数据可直接使用，也可回退旧版打开
- 新增设置项写在 `config.json` 的新键里，旧版读到多余键会原样保留
- 首次运行内容为空时自动补充示例图标（系统自带程序，覆盖全部 5 类）

## 运行要求
- **仅支持 Windows 11**（材质用 Mica；Win10 由系统自动回退纯色）
- **免安装**：解压即用（Windows App SDK 自包含），无需 MSIX 与证书

# ToolboxPanel 2.0.2 —— 功能补齐：图标管理 / 备份 / 搜索

> 在 2.0.1（WinUI 3 重写）基础上把**原版 v1.11.6 的外围功能逐项补齐**：
> 新建与编辑图标、右键菜单、批量管理、拖入添加、拖动排序重做、备份导入导出、搜索过滤、图标大小三档。
> 本版**未改动数据格式**，可与 v1.11.6 / 2.0.1 互相读写同一份 `data/`。

## 本版内容

### 新建 / 编辑图标
- 网格页**空白处右键** → 新建 **文件 / 文件夹 / 快捷方式 / 网址 / 命令** 五类图标（顺序与分组照原版）
- 文件 / 文件夹 / 快捷方式**先弹系统选择框**，选完自动预填名称与路径；`.lnk` 自动解析目标 / 参数 / 工作目录
- 图块右键 → **编辑属性…**：字段随类型变化（快捷方式多出 参数 / 工作目录 / 描述 / 自定义图标 + 索引）
- 校验不通过**不关窗**、错误直接显示在对话框里；图标按需重取，**旧缓存提取成功后才删**

### 右键菜单
- 图块：打开 / 用其他应用打开… / 打开文件位置 / ─ / 编辑属性… / 重命名 / 删除
  （「用其他应用打开…」只对 文件 / 文件夹 / 快捷方式 出现）
- 列表页行：编辑属性… / 重命名 / ─ / 删除；**空白处右键** = 新建列表项
- 打开类动作成功时不打扰（资源管理器 / 打开方式窗口本身就是反馈），失败才提示

### 批量管理
- 空白处右键 → 「批量管理」：图块显示勾选框 / 全选 / 批量删除勾选图标（二次确认，默认按钮=取消）
- 一次落盘并连带清理图标缓存；退出批量模式自动清空勾选

### 拖入添加
- 从资源管理器把 **文件 / 文件夹 / 快捷方式** 拖进窗口即创建图标（Copy 语义，不移动原文件）
- 重复 / 不存在的路径逐条给出提示；`.lnk` 解析不到目标时退回 `.lnk` 自身

### 拖动排序（重做后定稿）
- **按下即拖**（Windows 桌面式，无长按门槛）→ 在相邻图标处显示**插入竖条**（列表页为行间横条）→ 松手插入 → 立即落盘
- 拖动期间图标**不让位**；插入后**不再重播入场动画**
- 同页重排与跨页移动（拖到标签上停留切页 / 直接丢在标签上则追加到该页末尾）

### 搜索过滤 🆕
- 标题栏 **🔍 按钮**或 **Ctrl+F** 打开搜索栏，**Esc** 关闭（关闭即清空查询）
- 按 **名称 / 来源路径 / 目标路径** 过滤当前页；列表页按 **说明 / 路径**
- 右侧显示「**匹配 N / M**」；一个都没命中时显示「没有匹配的图标 / 列表项」
- **过滤状态下拖动排序仍然可用**（落点按"可见位"换算回真实列表位置后落库）
- 过滤进行中新建 / 拖入的项目**若与关键词不符则保持隐藏**（状态栏照常提示"已添加"）

### 备份 / 恢复（导入导出 ZIP）
- 设置面板最下方「**数据**」一节：显示数据目录 + 「导出备份…」「导入备份…」，并绑定快捷键 **Ctrl+Shift+E / Ctrl+Shift+I**
- 包结构：`metadata.json`（版本 / 导出时间 / 标签数 / 图标数）+ `data/` 下的数据与图标缓存
- 导入前**二次确认**，导入后自动重载设置与数据；带进度对话框与滚动日志（进行中不可关闭）
- 与**原版 Python 的备份包双向兼容**（原版导出的包能导入，本版导出的包原版也能导入）

### 关于 / 诊断
- 标题栏 **ⓘ** → 版本号、作者、**可点击**的项目地址、原版 6 条操作提示、**可展开的诊断信息**
- 版本号**运行时读程序集**（单一来源，绝不写死）

### 图标大小三档
- 设置面板「图标」一节：小 / 中 / 大；只改显示尺寸，不重新提取图标缓存

### 本版修复
- 「关于」对话框：不随深浅色切换 / 部分字体颜色错 / 诊断信息过长无法滚动
- 切换主题后标题栏与标签栏**部分图标、文字与强调条不跟随**（共 7 处漏网元素）
- **空页提示与数据脱钩**：给空页新建第一个图标后提示仍压在页面上、删光图标后提示不出现
- 拖动相关三处：插入指示线位置永远不对（定位属性放错容器）、插入后所有图标重播入场动画、同页**往后拖多走一格**

## 运行要求
- **仅支持 Windows 11**（窗口材质用 Mica；Win10 由系统自动回退纯色）
- **免安装**：解压即用（Windows App SDK 自包含），无需 MSIX 与证书

## 数据兼容
- `data/tabs.json` 格式**不变**（`version: 1`），v1.11.6 / 2.0.1 的数据可直接使用，也可回退旧版打开
- 新增设置项写在 `config.json` 的新键里，旧版读到多余键会原样保留
- 首次运行内容为空时自动补充示例图标（系统自带程序，覆盖全部 5 类）
